⌘2Infinity · Depth

一面會自己流動的封面牆

整個音樂庫鋪成一面沒有盡頭的封面牆，攤開這些年的收藏與品味。開著讓它緩緩流動，就這樣徜徉在封面之間，看到想聽的再點下去。

自動捲動：打開右上角的開關，封面牆會一直慢慢滑動，像一面會呼吸的唱片櫃。游標離開視窗時也會輕輕漂移，可以調整漂移速度。
  • 雙指縮放：從一次看上百張到大封面細看，五段大小
  • Magic 排序：依顏色、曲風、年代或隨機重新排列整面牆
  • 白光 hover：游標停在封面上，邊緣柔柔亮起

⌘3Cover Flow · Visual

找回最早 OS X 的 Cover Flow

一張一張翻過封面的那種沉浸感。中間的封面放大，兩側斜斜排開，背景光暈跟著中間的專輯變色。點中間的封面翻面看曲目。

  • 觸控板或方向鍵：左右滑過整個收藏
  • 光暈亮度可調：停下時背景要不要暗下來、暗多少，自己決定
  • 倒影與圓角：封面圓角、兩側變暗程度都能調整

音樂來源

自己的伺服器，或 YouTube Music

打開 Flione 時選一個音樂來源，之後在設定或側欄的帳號選單隨時切換。同樣的三種模式，兩邊都能用。

J

Jellyfin

把自己架的 Jellyfin 伺服器變成私人的音樂串流。真正擁有你的音樂，而不只是串流。

  • 無縫換曲，專輯一首接一首不停頓
  • Smart Shuffle、曲風、編輯播放清單
  • 伺服器欄位只填主機名稱也能自動找到
▶

YouTube Music

在 Flione 裡開 Google 登入視窗，收藏的專輯、喜歡的歌曲、播放清單、播放記錄和搜尋，全部接到同樣的三種模式。

  • 用 Google 帳號登入，不另外保存密碼
  • 按愛心會同步回 YouTube Music
  • 播放由隱藏的網頁播放器負責

建議使用 YouTube Premium 帳號：免費帳號播放時可能插播廣告。Flione 使用非官方的 InnerTube API，Google 改版時可能暫時失效。

兩邊的登入都會保留：切換音樂來源不用重新登入，播放佇列也各自記得。

安裝

下載 dmg，拖進「應用程式」

跟著四個步驟做，大約一分鐘。第三步會用到「終端機」，不用怕，複製貼上就好。

  1. 按這裡的「下載最新版」，從 GitHub 下載 .dmg 檔：Apple 晶片（M1 以後）選 AppleSilicon，Intel 處理器選 Intel。不確定的話，點左上角 → 關於這台 Mac 看「晶片」或「處理器」。
  2. 雙擊 dmg 打開，把 Flione 拖進旁邊的「應用程式」資料夾。
  3. 打開「終端機」：按 ⌘ + 空白鍵 叫出 Spotlight，輸入「終端機」（英文系統輸入 Terminal），按 Return。
  4. 按下面黑色框右上角的「複製」，回到終端機按 ⌘ + V 貼上，再按 Return。Flione 就會打開，之後從「應用程式」直接開就好。
xattr -dr com.apple.quarantine /Applications/Flione.app && open /Applications/Flione.app

蛤？這是在幹嘛？Flione 是免費的自簽 app，沒有經過 Apple 公證。我也不是靠開發 App 維生，純粹是做自己覺得好用、好看的小東西，繳不起 Apple 每年的開發者規費⋯⋯所以 macOS 會擋下第一次開啟。這行指令只是拿掉下載時被加上的「隔離」標記，再幫你打開 Flione，不會改動其他東西，只需要做一次。

需求：macOS 14 以上（Liquid Glass 效果需要 macOS 26），以及一台 Jellyfin 伺服器或一個 YouTube Music 帳號。第一次啟動時在登入畫面選擇音樂來源。也可以照 README 用 Xcode 從原始碼建置。

開發的故事

Flione 的起點是一台自己架設的 Jellyfin。累積二十幾年的 iTunes 音樂庫重新整理入庫，成了私人的音樂串流。

音樂都回來了，能用的播放器卻都不太好看，也不夠現代。於是有了 Flione：要有 Spotify 那樣的側欄，要有一面緩緩流動、攤開收藏與品味的封面牆，也要找回最早 OS X 的 Cover Flow。

Flione 想讓收藏音樂這件事文藝復興：真正擁有你的音樂，而不只是串流。

Jellyfin+Infinity+Clione=Flione

Jellyfin 和 Infinity 都有「fin」，取它的 F；「lione」來自 Clione，也就是海天使。三種模式是海天使在音樂海洋裡的三種動態：Modern 是日常的漂浮，Infinity 游向深海，Cover Flow 穿梭在漂浮的群落之間。
