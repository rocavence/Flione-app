# Flione — 命名

**Flione = Jellyfin + Infinity + Clione（海天使）**

| 來源 | 取用的部分 | 代表 |
|---|---|---|
| Jellyfin | fin | 起點：Flione 一開始是為自己的 Jellyfin 音樂庫做的播放器 |
| Infinity | fin | 無盡：整個音樂庫鋪成一面沒有終點的封面牆 |
| Clione | lione | 意象：海天使，在自己的音樂海洋裡漂浮、探索與發現 |

Jellyfin 與 Infinity 都有 fin，取它的 F；再接上 Clione 的 lione，成為 Flione。

## 名字的演進

1. **Finity**：最早的視覺設計系統（見 `finity-visual-design-system-legacy.md`）
2. **Finify**：最早的程式與 app 名稱，程式內部的型別前綴、bundle id、設定鍵仍沿用
3. **Flione**：加入海天使的意象，成為對外名稱（D25）

後來加入 YouTube Music 作為第二個音樂來源，名字仍保留 Jellyfin 的 fin，記錄 Flione 的起點。

三種模式如何對應海天使的狀態，見 [three-browsing-modes.md](three-browsing-modes.md)。
